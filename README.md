# Dreamy Scroll 3D

스크롤하면 카메라가 안개 낀 3D 세계를 지나가며, 오브젝트가 **흩어지고 → 문을 통과하고 → 다시 모이는** 흐름의 웹페이지 샘플입니다.
결과물(웹페이지), 사람이 읽는 설계도, AI에게 넘기는 프롬프트를 함께 담았습니다.

**▶ 웹페이지 보기:** https://p-sho.github.io/dreamy-scroll-3d/

---

## 파일 구성

| 파일 | 무엇인가 | 언제 보나 |
|---|---|---|
| [`index.html`](index.html) | 가을 테마로 만든 3D 스크롤 웹페이지 (실제 결과물) | 완성된 모습을 보거나 코드를 참고할 때 |
| [`FLOW_TEMPLATE.md`](FLOW_TEMPLATE.md) | 오브젝트와 문구를 빈칸으로 둔 흐름·느낌 설계도 | 새 테마를 기획하거나 연출 원리를 이해할 때 |
| [`PROMPT.md`](PROMPT.md) | AI에게 그대로 붙여넣는 생성 프롬프트 | AI로 새 테마 버전을 바로 만들 때 |
| `README.md` | 지금 보고 있는 안내 문서 | 처음 저장소에 들어왔을 때 |

세 파일의 관계:

```
FLOW_TEMPLATE.md  ──(설계를 AI 지시문으로 옮김)──▶  PROMPT.md
       │                                              │
       └──────(빈칸을 가을 테마로 채워 구현)──────────▶  index.html
```

## 1. `index.html` — 가을 버전 웹페이지

빌드 없이 실행되는 HTML 한 파일입니다. Three.js r160을 CDN에서 불러오고, 3D 모델이나 이미지 파일 없이 모든 형태와 텍스처를 코드로 만듭니다.

**7막 흐름**

| 막 | 스크롤 | 장면 |
|---|---|---|
| 0 완성 | 0% | 언덕 위 단풍나무, 가지에 걸린 등불 |
| 1 근접 | 10% | 단풍잎 1300장으로 채운 나무 가까이 |
| 2 해체 | 12–28% | 잎들이 바람에 소용돌이치며 흩날리고 가지만 남음 |
| 3 부유 | 30–45% | 공중에 떠서 도는 거대 도토리 |
| 4 통과 | 48–62% | 조각난 나무 고리와 낙엽 소용돌이를 지나 섬광 → 물결 |
| 5 주인공 | 70–82% | 그루터기 위 털 다람쥐, 둘레에 버섯 |
| 6 재조립 | 84–100% | 흩어진 잎이 모여 다시 한 그루의 나무가 됨 |

**주요 기법**
- 스크롤 진행값으로 움직이는 카메라 경로 (CatmullRom 곡선)
- 조각 흩어짐 / 재조립 (InstancedMesh, 조각별 시간차와 소용돌이)
- 캔버스로 그린 단풍잎 텍스처 (톱니 테두리, 잎맥, 잎자루) + 잎 모양 그림자
- 셸 텍스처링으로 만든 부시시한 털
- 거리 기반 포탈 통과 연출 (섬광, 동심원 물결, 색번짐)
- 블룸, 색번짐, 헤이즈, 그레인, 비네팅을 합친 몽롱한 후처리

## 2. `FLOW_TEMPLATE.md` — 흐름과 느낌 설계도

"무엇을 보여주는지"는 비우고 **"어떻게 넘어가고 어떤 느낌인지"만** 정리한 문서입니다.

- 빈칸 채우기 시트 (상징물, 조각, 문, 캐릭터, 포인트 색 등)
- 7막 흐름과 감정 곡선, 막별 연출 사양
- 스크롤 타이밍 시트
- 전환 기법 3종: 해체/재조립, 게이트 통과, 장면 간 이음
- 분위기 규칙: 색, 대기, 후처리, 움직임, 재질
- 문구 구조, 화면 배치, 테마 변형 예시, 제작 순서

## 3. `PROMPT.md` — AI 생성 프롬프트

`FLOW_TEMPLATE.md`의 내용을 AI가 바로 실행할 수 있는 지시문으로 옮긴 문서입니다.

1. **빈칸 채우기:** 테마 설정값을 채움
2. **메인 프롬프트:** 그대로 복사해 AI에게 보냄
3. **채운 예시:** 지금 가을 버전의 설정값 + 다른 테마 아이디어
4. **수정 프롬프트 모음:** 결과를 다듬는 짧은 지시문 (더 몽롱하게, 털 더 부시시하게, 저사양 대응 등)

## 새 테마 버전 만드는 법

1. `PROMPT.md`의 빈칸을 원하는 테마로 채웁니다. (예: 도서관, 정원, 사막, 우주)
2. 메인 프롬프트와 함께 AI에게 보내 HTML 파일을 받습니다.
3. 수정 프롬프트로 다듬습니다.
4. 연출 원리가 궁금하거나 직접 고치고 싶으면 `FLOW_TEMPLATE.md`와 `index.html` 코드를 참고합니다.

## 로컬에서 실행

ES 모듈과 CDN을 쓰기 때문에 파일을 더블클릭하기보다 로컬 서버로 여는 것을 권장합니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 엽니다.

## 참고

- 최신 Chrome / Edge 권장. 털과 후처리 때문에 내장 그래픽에서는 프레임이 낮을 수 있습니다.
- 가볍게 하려면 `index.html` 안의 `LAYERS`(털 겹 수), `setPixelRatio`, 블룸 강도 값을 낮추세요.
- 연출 흐름은 인스타그램에서 본 3D 스크롤 웹사이트 영상을 참고했고, 오브젝트·코드·문구는 모두 새로 만들었습니다.
