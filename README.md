# Dreamy Scroll 3D

스크롤하면 카메라가 안개 낀 3D 세계를 이동하며, 오브젝트가 **흩어지고 → 문을 통과하고 → 다시 모이는** 흐름의 웹페이지 샘플입니다.
Three.js(r160) 기반의 단일 HTML 파일이라 빌드 없이 바로 열 수 있습니다.

## 샘플

| 파일 | 내용 |
|---|---|
| [`site.html`](site.html) | 겨울 버전: 얼음 블록 이글루, 떠 있는 얼음 결정, 돌 고리 포탈, 털 곰 |
| [`site_autumn.html`](site_autumn.html) | 가을 버전: 단풍나무, 도토리, 낙엽 소용돌이 포탈, 털 다람쥐 |
| [`index.html`](index.html) | 두 버전과 문서로 연결되는 랜딩 페이지 |

## 문서

| 파일 | 내용 |
|---|---|
| [`FLOW_TEMPLATE.md`](FLOW_TEMPLATE.md) | 오브젝트·문구를 빈칸으로 둔 흐름과 느낌의 설계도. 빈칸만 채우면 새 테마로 재사용 가능 |
| [`DESIGN_GUIDE.md`](DESIGN_GUIDE.md) | 겨울 버전의 색, 재질, 효과, 수치를 정리한 디자인 기록 |

## 주요 기법

- 스크롤 진행값으로 제어하는 카메라 경로 (CatmullRom 곡선 2개)
- 조각 흩어짐 / 재조립 (InstancedMesh + 조각별 시간차)
- 셸 텍스처링으로 만든 부시시한 털
- 거리 기반 포탈 통과 연출 (섬광, 물결, 색번짐)
- 블룸, 색번짐, 헤이즈, 그레인, 비네팅을 합친 몽롱한 후처리

## 로컬에서 실행

ES 모듈과 CDN을 쓰기 때문에 파일을 더블클릭하기보다 로컬 서버로 여는 것을 권장합니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 엽니다.

## 참고

- 최신 Chrome / Edge 권장. 털과 후처리 때문에 내장 그래픽에서는 프레임이 낮을 수 있습니다.
- 성능 조절: 각 HTML 안의 `LAYERS`(털 겹 수), `setPixelRatio`, 블룸 강도 값을 낮추면 가벼워집니다.
